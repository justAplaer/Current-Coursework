# Current-Coursework
Some of my current programming coursework and technical exercises, exploring algorithms, software development, and engineering concepts while building a stronger foundation for Electrical and Computer Engineering.

JUnit Team Test Case:

A Java project that models a sports team’s season statistics, including games played, points scored, wins, averages, sorting, and season resets. It includes a thorough JUnit test suite covering normal behavior, invalid inputs, constructors, comparisons, and edge cases.

Levenshtein Distance Finder:

A Java word-ladder solver that finds the shortest transformation path between two same-length dictionary words, changing one letter at a time. It builds a graph of neighboring words, uses breadth-first search to calculate the distance, and returns the transformation path when one exists.

Student List GUIL:

A Java Swing application for displaying student records and grade averages in a table. Users can sort the roster alphabetically or by average grade, while the supporting model handles parsing student data, calculating averages, validation, and comparable objects.

Recursion Practice:

A Java practice program demonstrating recursion through two classic problems: checking whether a string is a palindrome and printing squares in a specified recursive order. It focuses on recursive base cases, string reduction, and call-stack behavior.
